## Project notes

- Static export only (`output: "export"`): no route handlers, server actions, cookies or rewrites.
- `public/data/tn.json` is generated by `scripts/build-data.ts`; edit the script, never the JSON.
- Booking maths lives in `src/lib/booking.ts` (IST-based, pure) with tests in `booking.test.ts`.
- No map (removed for speed and accessibility). Layout: `App.tsx` (top bar, journey bar, side summary, tabs). A train's route is `RouteStops` in `TrainCard.tsx`.
- Reminder links/`.ics` generation live in `src/lib/reminders.ts` (tested).
- Board filters, sorting and time-of-day/status sections live in `src/lib/filters.ts` (tested).
- Advance-booking rules: `src/lib/advance.ts` (tested). Holiday list: `src/lib/holidays.ts`; update it each year from the Tamil Nadu holidays G.O. (dates verified against the G.O. PDF, not news sites).
- GTFS → dataset logic is `src/lib/buildDataset.ts`, shared by `scripts/build-data.ts` and the in-browser Sync (`src/workers/sync.worker.ts`, result saved in localStorage `tn.dataset`).
- Run `bun run check` before committing.
- SEO/AEO: metadata in `src/app/layout.tsx`; JSON-LD (WebApplication + FAQPage), FAQ and footer are rendered into the static HTML by `src/app/page.tsx`; FAQ text lives in `src/lib/faq.ts`. `robots.ts`, `sitemap.ts`, `manifest.ts`, `opengraph-image.tsx` are static.
- Set `NEXT_PUBLIC_SITE_URL` (Cloudflare build variable) to the live address so canonical links, sitemap and share previews are correct (`src/lib/site.ts`).
- Cache/security headers for Cloudflare static assets: `public/_headers`.
- The Advance/Holidays tabs are lazy-loaded (`next/dynamic`); keep heavy, rarely used UI out of the first bundle.
- Hosting: main site is Firebase Hosting `https://bogiey.web.app` (project `bogiey`, `firebase.json`, deployed by `.github/workflows/firebase-deploy.yml` with secret `FIREBASE_SERVICE_ACCOUNT_BOGIEY`). Cloudflare (Workers static assets, `wrangler.jsonc`) builds the same commit as a mirror. Keep cache/security headers in `public/_headers` and `firebase.json` in sync. Canonical/sitemap always point at `SITE_URL`.
